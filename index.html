01. Aljabar

Persamaan, pertidaksamaan, eksponen, dan logaritma.

Identitas Aljabar

(a + b)² = a² + 2ab + b²

(a - b)² = a² - 2ab + b²

(a + b)(a - b) = a² - b²

(a + b)³ = a³ + 3a²b + 3ab² + b³

(a - b)³ = a³ - 3a²b + 3ab² - b³

Persamaan Kuadrat

ax² + bx + c = 0

x = (-b ± √D) / 2a

D = b² - 4ac

Jumlah akar = -b/a

Hasil kali akar = c/a

Sumbu simetri = -b/2a

Titik puncak = (-b/2a, -D/4a)

Eksponen

aᵐ × aⁿ = aᵐ⁺ⁿ

aᵐ / aⁿ = aᵐ⁻ⁿ

(aᵐ)ⁿ = aᵐⁿ

(ab)ⁿ = aⁿbⁿ

a⁰ = 1

a⁻ⁿ = 1/aⁿ

a¹/ⁿ = ⁿ√a

Logaritma

logₐ 1 = 0

logₐ a = 1

logₐ (xy) = logₐ x + logₐ y

logₐ (x/y) = logₐ x - logₐ y

logₐ xⁿ = n logₐ x

logₐ b = log b / log a

Nilai Mutlak

|x| = x, jika x ≥ 0

|x| = -x, jika x kurang dari 0

|x| = √x²

|x-a| = jarak x terhadap a

Pertidaksamaan

a > b : lebih besar

a < b : lebih kecil

a ≥ b : lebih besar atau sama dengan

a ≤ b : lebih kecil atau sama dengan

Jika dikali bilangan negatif, tanda berbalik.

Sistem Persamaan Linear

ax + by = c

dx + ey = f

x = (ce - bf)/(ae - bd)

y = (af - cd)/(ae - bd)

02. Geometri

Bangun datar, bangun ruang, dan geometri analitik.

Persegi dan Persegi Panjang

Persegi: L = s²

K = 4s

Persegi panjang: L = p × l

K = 2(p + l)

Diagonal persegi = s√2

Segitiga

L = ½ × alas × tinggi

K = a + b + c

Rumus Heron:

L = √[s(s-a)(s-b)(s-c)]

s = (a+b+c)/2

Segiempat

Jajar genjang: L = a × t

Trapesium: L = ½(a+b)t

Belah ketupat: L = ½d₁d₂

Layang-layang: L = ½d₁d₂

Lingkaran

L = πr²

K = 2πr

d = 2r

Panjang busur = (θ/360°) × 2πr

Luas juring = (θ/360°) × πr²

Kubus dan Balok

Kubus: V = s³

L permukaan = 6s²

Diagonal ruang = s√3

Balok: V = p × l × t

L permukaan = 2(pl + pt + lt)

Prisma dan Limas

Prisma: V = La × t

L permukaan = 2La + Ka × t

Limas: V = ⅓ × La × t

Tabung dan Kerucut

Tabung: V = πr²t

L = 2πr(r+t)

Kerucut: V = ⅓πr²t

Garis pelukis: s = √(r²+t²)

L = πr(r+s)

Bola

V = ⁴⁄₃πr³

L = 4πr²

Setengah bola tanpa alas:

L = 2πr²

Pythagoras

c² = a² + b²

c = √(a²+b²)

a = √(c²-b²)

b = √(c²-a²)

Kesebangunan

a₁/a₂ = b₁/b₂ = c₁/c₂

Skala = jarak gambar / jarak sebenarnya

Perbandingan luas = k²

Perbandingan volume = k³

Geometri Analitik

d = √[(x₂-x₁)²+(y₂-y₁)²]

M = ((x₁+x₂)/2, (y₁+y₂)/2)

Gradien: m = (y₂-y₁)/(x₂-x₁)

Persamaan Garis

y = mx + c

y - y₁ = m(x - x₁)

ax + by + c = 0

Garis sejajar: m₁ = m₂

Garis tegak lurus: m₁m₂ = -1

03. Trigonometri

Perbandingan sudut, identitas, dan aturan segitiga.

Perbandingan Trigonometri

sin θ = depan / miring

cos θ = samping / miring

tan θ = depan / samping

tan θ = sin θ / cos θ

cot θ = cos θ / sin θ

Identitas Trigonometri

sin² θ + cos² θ = 1

1 + tan² θ = sec² θ

1 + cot² θ = cosec² θ

sec θ = 1/cos θ

cosec θ = 1/sin θ

Sudut Istimewa

sin 0° = 0

sin 30° = ½

sin 45° = √2/2

sin 60° = √3/2

sin 90° = 1

cos 0° = 1

cos 30° = √3/2

cos 45° = √2/2

cos 60° = ½

cos 90° = 0

Aturan Sinus dan Cosinus

a/sin A = b/sin B = c/sin C

a² = b² + c² - 2bc cos A

b² = a² + c² - 2ac cos B

c² = a² + b² - 2ab cos C

Rumus Jumlah dan Selisih

sin(A+B) = sin A cos B + cos A sin B

sin(A-B) = sin A cos B - cos A sin B

cos(A+B) = cos A cos B - sin A sin B

cos(A-B) = cos A cos B + sin A sin B

Sudut Ganda

sin 2A = 2 sin A cos A

cos 2A = cos² A - sin² A

cos 2A = 1 - 2sin² A

cos 2A = 2cos² A - 1

tan 2A = 2tan A/(1-tan² A)

04. Statistika

Pengolahan, penyajian, dan analisis data.

Ukuran Pemusatan

Mean = Σx / n

Mean berfrekuensi = Σfx / Σf

Median = nilai tengah

Modus = nilai paling sering muncul

Median Data Berkelompok

Me = Tb + ((n/2 - F)/f) × p

Tb = tepi bawah kelas median

F = frekuensi kumulatif sebelum kelas median

f = frekuensi kelas median

Modus Data Berkelompok

Mo = Tb + (d₁/(d₁+d₂)) × p

d₁ = frekuensi modus - frekuensi sebelumnya

d₂ = frekuensi modus - frekuensi sesudahnya

Kuartil

Q₁ = kuartil bawah

Q₂ = median

Q₃ = kuartil atas

Jangkauan interkuartil = Q₃ - Q₁

Simpangan kuartil = (Q₃-Q₁)/2

Varians dan Simpangan Baku

Varians populasi = Σ(x-μ)²/n

Varians sampel = Σ(x-x̄)²/(n-1)

Simpangan baku = √varians

Ukuran Penyebaran

Jangkauan = Xmaks - Xmin

Jangkauan interkuartil = Q₃ - Q₁

05. Peluang dan Kombinatorika

Peluang kejadian, permutasi, dan kombinasi.

Peluang

P(A) = n(A)/n(S)

0 ≤ P(A) ≤ 1

P(Aᶜ) = 1 - P(A)

P(A ∪ B) = P(A)+P(B)-P(A ∩ B)

Peluang Kejadian

P(A ∩ B) = P(A) × P(B)

P(A|B) = P(A ∩ B)/P(B)

Faktorial

n! = n × (n-1) × ... × 1

0! = 1

Permutasi

P(n,r) = n!/(n-r)!

Permutasi seluruh unsur = n!

Kombinasi

C(n,r) = n!/[r!(n-r)!]

C(n,r) = C(n,n-r)

Aturan Pencacahan

Aturan penjumlahan = m + n

Aturan perkalian = m × n

06. Barisan dan Deret

Pola bilangan aritmetika dan geometri.

Barisan Aritmetika

Uₙ = a + (n-1)b

b = Uₙ - Uₙ₋₁

Deret Aritmetika

Sₙ = n/2 (a + Uₙ)

Sₙ = n/2 [2a+(n-1)b]

Barisan Geometri

Uₙ = arⁿ⁻¹

r = Uₙ/Uₙ₋₁

Deret Geometri

Sₙ = a(rⁿ-1)/(r-1)

Sₙ = a(1-rⁿ)/(1-r)

Deret Geometri Tak Hingga

S∞ = a/(1-r)

Syarat: |r| < 1

Bilangan Khusus

Jumlah n bilangan asli = n(n+1)/2

Jumlah n bilangan ganjil pertama = n²

Jumlah kuadrat = n(n+1)(2n+1)/6

07. Matriks

Operasi matriks, determinan, dan invers.

Operasi Matriks

A + B = penjumlahan elemen seposisi

A - B = pengurangan elemen seposisi

kA = setiap elemen dikali k

Determinan Matriks 2×2

A = [a b; c d]

det(A) = ad - bc

Invers Matriks 2×2

A⁻¹ = 1/(ad-bc)

× [d -b; -c a]

Syarat: ad-bc ≠ 0

Determinan Matriks 3×3

det(A) = a(ei-fh)-b(di-fg)+c(dh-eg)

Transpose Matriks

(Aᵀ)ᵀ = A

(A+B)ᵀ = Aᵀ+Bᵀ

(AB)ᵀ = BᵀAᵀ

Persamaan Matriks

AX = B

X = A⁻¹B

08. Kalkulus

Limit, turunan, dan integral.

Limit

lim x→a f(x) = L

lim (f+g) = lim f + lim g

lim (f×g) = lim f × lim g

Limit Trigonometri

lim x→0 sin x/x = 1

lim x→0 tan x/x = 1

lim x→0 (1-cos x)/x² = ½

Turunan Dasar

f(x) = xⁿ

f'(x) = nxⁿ⁻¹

(c)' = 0

(f+g)' = f'+g'

Aturan Turunan

(fg)' = f'g + fg'

(f/g)' = (f'g-fg')/g²

(f(g(x)))' = f'(g(x))g'(x)

Turunan Trigonometri

(sin x)' = cos x

(cos x)' = -sin x

(tan x)' = sec² x

(cot x)' = -cosec² x

Integral Tak Tentu

∫xⁿ dx = xⁿ⁺¹/(n+1) + C

n ≠ -1

∫1/x dx = ln|x| + C

Integral Trigonometri

∫sin x dx = -cos x + C

∫cos x dx = sin x + C

∫sec² x dx = tan x + C

Integral Tentu

∫ₐᵇ f(x) dx = F(b)-F(a)

F'(x) = f(x)

Aplikasi Turunan

Gradien garis singgung = f'(x)

Titik stasioner: f'(x) = 0

Kecepatan = turunan posisi

Percepatan = turunan kecepatan

09. Vektor

Operasi vektor dan perkalian skalar.

Panjang Vektor

|a| = √(x²+y²)

|a| = √(x²+y²+z²)

Operasi Vektor

a + b = (a₁+b₁, a₂+b₂)

a - b = (a₁-b₁, a₂-b₂)

ka = (ka₁, ka₂)

Perkalian Titik

a · b = a₁b₁ + a₂b₂

a · b = |a||b| cos θ

cos θ = (a·b)/(|a||b|)

Vektor Satuan

u = a/|a|

Panjang vektor satuan = 1

10. Transformasi Geometri

Translasi, refleksi, rotasi, dan dilatasi.

Translasi

(x, y) → (x+a, y+b)

Refleksi

Sumbu X: (x,y) → (x,-y)

Sumbu Y: (x,y) → (-x,y)

Garis y=x: (x,y) → (y,x)

Garis y=-x: (x,y) → (-y,-x)

Garis y=k: (x,y) → (x,2k-y)

Garis x=k: (x,y) → (2k-x,y)

terhadap titik asal: (x,y) → (-x,-y)

Rotasi

90° berlawanan jarum jam: (x,y) → (-y,x)

90° searah jarum jam: (x,y) → (y,-x)

180°: (x,y) → (-x,-y)

Dilatasi

(x,y) → (kx,ky)

k = faktor skala
